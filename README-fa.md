# n11-mcp 🇹🇷

mcp-name: io.github.mohammad-abbasi-sh/n11-mcp

سرور MCP غیررسمی و **فقط‌خواندنی** برای **n11.com**، مارکت‌پلیس شماره‌ی
۳ ترکیه — جست‌وجو در میلیون‌ها کالا، خواندن جزئیات کالا (قیمت، قیمت
لیست، موجودی، امتیاز، فروشنده، دسته)، خواندن نظرهای مشتریان، مرور ۱۱
دسته‌ی اصلی، و گرفتن آمار قیمت (کمترین / میانه / میانگین / بیشترین)
برای هر جست‌وجو.

> ساخته‌ی محمد عباسی در چارچوب «کارخانه‌ی MCP ترکیه» (به سبک سپهر). هیچ
> وابستگی‌ای به n11.com ندارد.

## برای ایجنت‌های هوش مصنوعی

به پیکربندی MCP client خود اضافه کنید (stdio):

```json
{
  "mcpServers": {
    "n11": {
      "command": "uvx",
      "args": ["n11-mcp"]
    }
  }
}
```

یا به‌صورت محلی اجرا کنید: `python -m n11_mcp.server`
(نیازمند `mcp<2` و `curl-cffi`).

## ابزارها

| ابزار | توضیح |
|------|-------|
| `n11_search` | جست‌وجوی کالا با کلیدواژه — `query` (مثل «iphone» یا «kablosuz kulaklık»)، `sort` (‏«relevance» / ‏«price_asc» / ‏«price_desc»)، `limit` از ۱ تا ۲۴، `page` از ۱؛ برمی‌گرداند: عنوان، قیمت به لیر، قیمت لیست، برند، SKU، آدرس، عکس، وضعیت موجودی |
| `n11_product_detail` | جزئیات یک کالا (`product` = آدرس کامل یا مسیر حاوی «/urun/…»): نام، برند، قیمت به لیر، قیمت لیست، وضعیت موجودی، امتیاز، تعداد نظر، فروشنده (شرکت، نام فروشگاه، نشان فروشگاه مجاز، امتیاز فروشنده، شهر ارسال)، مسیر دسته، توضیح، عکس‌ها |
| `n11_list_categories` | ۱۱ دسته‌ی اصلی: نام ترکی، آدرس، اسلاگ |
| `n11_price_stats` | آمار قیمت برای یک جست‌وجو: تعداد، کمترین / میانه / میانگین / بیشترین قیمت (لیر) |
| `n11_product_reviews` | نظرهای اخیر مشتریان برای یک کالا: نویسنده و امتیاز ستاره‌ای (سایت n11 متن نظرها را سمت سرور رندر نمی‌کند) |

نمونه‌ی خروجی (`n11_search` / ‏«iphone»):

```json
{"query": "iphone", "count": 10, "products": [
  {"title": "Apple iPhone 17 Pro Max 256 GB (Apple Türkiye Garantili)",
   "url": "https://www.n11.com/urun/apple-iphone-17-pro-max-256-gb-apple-turkiye-garantili-100816929",
   "sku": "127340433485", "brand": "Apple", "price_try": 112434.28,
   "original_price_try": 117119.04, "in_stock": true}, …]}
```

## چطور کار می‌کند؟

سایت n11.com به کلاینت‌های HTTP ساده جواب می‌دهد؛ با این حال لایه‌ی
انتقال از جعل TLS کروم (`curl-cffi`، ‏`chrome120`) استفاده می‌کند تا
یک بررسی ربات سخت‌گیرانه‌تر سرور را از کار نیندازد. API عمومی JSON
ندارد — داده‌ها از HTML رندرشده‌ی سمت سرور می‌آیند: صفحه‌های جست‌وجو
بلوک ItemList از نوع JSON-LD دارند (۲۰ کالا در هر صفحه)، صفحه‌های کالا
JSON-LD از نوع Product به‌همراه مسیر دسته (breadcrumb) و آبجکت JSON
فروشنده، و صفحه‌ی اصلی ۱۱ دسته‌ی اصلی را دارد. درخواست‌ها با فاصله‌ی
حدود ۰٫۸ ثانیه فرستاده می‌شوند؛ همه‌چیز فقط‌خواندنی است، بدون لاگین و
بدون کلید API.

## نصب

```bash
uvx n11-mcp        # اجرای مستقیم (نیازمند uv)
# یا
pip install n11-mcp
n11-mcp            # اجرای سرور MCP روی stdio
```

## تست‌ها

```bash
python -m venv .venv && .venv/bin/pip install -e .
.venv/bin/python -m unittest discover -s tests -v
```

تست‌های آفلاین روی نمونه‌های ضبط‌شده از صفحه‌های واقعی اجرا می‌شوند
(دریافت‌شده در ۲۰۲۶-۱۱-۰۶)؛ تست‌های زنده به n11.com وصل می‌شوند.
